## 4. 프로덕트 상세 설명 (**1000자 이내 필수** — 그대로 복붙용, 792자)

```
AI 코딩 에이전트(Claude·Gemini·Codex 등)는 강력하지만, 팀 단위로 운영하려면 막막합니다. 누가 무엇을 시켰는지, 지금 어디까지 됐는지 흩어져 있고, 에이전트를 터미널에서 일일이 띄워야 하고, 토큰·검수 시간 같은 실제 원가는 보이지 않습니다.

Springware IVE는 이 모든 걸 하나의 웹 대시보드로 묶었습니다.

작동은 단순합니다. GitLab·GitHub 이슈에 라벨 하나만 붙이면 스캐너가 감지해 AI 에이전트를 배정하고, 레포 clone → 코드 수정 → MR/PR 생성까지 자동으로 끝냅니다. 이후 개발 → 검증 → 확인 → 완료의 5단계 워크플로우로 상태를 관리하고, 단계가 바뀔 때마다 담당자에게 Slack·메일로 알립니다. 사람은 코드를 짜는 대신 방향과 가치 판단에만 집중합니다.

핵심 기능
• Slack 통합: 봇 원클릭 설치, 멘션으로 에이전트와 대화, 단계별 담당자 DM 알림, 첨부 이미지 분석, Slack 로그인
• 멀티 CLI 에이전트: Claude·Gemini·Codex·OpenCode를 한 화면에서 배정·병렬 실행
• 실시간 추적: xterm.js 터미널로 작업 로그를 라이브로 보고, 멈춘 작업은 즉시 강제종료
• 비용·원가 리포트: AI 토큰 비용과 사람 검수 시간을 함께 집계, 통화·환율 변환
• 보안·셀프호스팅: 토큰 AES-256 암호화, JWT 인증, Docker로 내부망에서 운영

AI 에이전트를 팀 차원에서 안전하게 운영하고, 자동화의 실제 원가까지 숫자로 보고 싶은 개발팀에게 맞습니다.

"AI가 개발하고, 사람은 가치를 관리한다."
```

## 4-B. (참고) 메이커 코멘트 — 더 긴 스토리 버전

> 상세 설명과 별개로, 메이커 로그/코멘트에 쓸 수 있는 길이 제한 없는 버전입니다.

### 🧩 어떤 문제를 풀었나요?

AI 코딩 에이전트(Claude Code, Gemini CLI, Codex 등)는 강력하지만, 막상 **팀 단위로 굴리려면** 곤란합니다.

- 누가 어떤 이슈를 시켰고, 지금 어디까지 됐는지 흩어져 있습니다.
- 에이전트를 터미널에서 일일이 띄우고, 끝나면 직접 MR을 만들어야 합니다.
- 토큰을 얼마나 썼고 사람 검수 시간이 얼마나 들었는지 — **원가가 보이지 않습니다.**

**Springware IVE**는 이걸 하나의 웹 대시보드로 묶었습니다.

### ⚙️ 어떻게 동작하나요?

```
GitLab/GitHub 이슈에 'IVE' 라벨 부착
        │  스캐너가 주기적으로 감지
   배정된 AI 에이전트가 실행
        │  레포 clone → 코드 수정 → MR/PR 생성
   5단계 워크플로우(개발 → 검증 → 확인 → 완료)로 상태 관리
        │  Slack DM / 메일로 단계 전이 알림
   토큰·비용·사람 검수 시간까지 리포트로 집계
```

이슈에 라벨 하나만 붙이면, **감지 → 코드 수정 → MR/PR 생성**까지 사람 손을 떠납니다.
사람은 방향과 가치 판단(검증·확인)에만 집중합니다.

### ✨ 핵심 기능

- **Slack 통합 (v1.5.0 간판 기능)** — 워크스페이스 봇 원클릭 설치(OAuth), 채널/스레드에서 **멘션으로 에이전트와 대화**(스레드별 독립 세션), 단계 전이별 담당자 **DM 알림**(검증대기→검증자 / 확인대기→확인자 / 완료→생성자), 첨부 이미지 분석, Slack 계정으로 로그인까지
- **멀티 CLI 에이전트** — Claude · Gemini · Codex · OpenCode를 한 화면에서 배정·병렬 실행
- **자동 스캐너** — GitLab/GitHub 이슈를 주기적으로 폴링해 자동 배정 (상태는 로컬 DB로만 관리, 원격엔 라벨만)
- **실시간 실행 추적** — xterm.js 터미널로 에이전트 작업 로그를 라이브로 보고, 멈춘 작업은 즉시 강제종료
- **5단계 워크플로우** — 개발 → 검증 대기 → 확인 대기 → 완료, 단계별 담당자에게 Slack/메일 알림
- **비용·원가 리포트** — AI 토큰 비용 + 사람 검수 시간(단가 배수 적용)을 함께 집계, 통화·환율 변환
- **보안** — 액세스 토큰 AES-256-GCM 암호화, JWT 인증, 이용약관·개인정보처리방침·오픈소스 라이선스 고지 내장

### 🛠 기술 스택

`Next.js 16` · `React 19` · `TypeScript` · `Tailwind CSS 4` · `node-pty` · `WebSocket` · `SQLite(better-sqlite3)` · `xterm.js` · `next-intl(ko/en)`

### 🚀 누구에게 좋은가요?

- AI 에이전트를 **팀/조직 차원에서** 운영하고 싶은 개발팀
- 셀프호스팅(Docker)으로 **내부망에서 안전하게** 굴리고 싶은 곳
- AI 자동화의 **실제 원가(토큰+사람 시간)** 를 숫자로 보고 싶은 조직
